# DACLAW - 해커톤 올인원 플랫폼

해커톤 탐색부터 팀 매칭, 제출, 성장 추적, 대회 운영까지 — 참가자와 운영자 모두를 위한 해커톤 플랫폼.

> Dacon 바이브코딩 대회 출품작

## 실행 방법

```bash
cd daclaw
npm install
npm run dev
```

## 배포

Vercel 배포 시 Root Directory를 `daclaw`로 설정하세요.

## 기술 스택

- Next.js 16 / React 19
- Tailwind CSS 4
- Zustand (상태관리)
- Framer Motion (애니메이션)
- Recharts (차트)
- Lucide React (아이콘)
